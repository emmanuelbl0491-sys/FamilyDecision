# tecnico/aprendizaje/ — Práctica para el Arquitecto y colaboradores técnicos

Este proyecto es también un **campo de entrenamiento**.

| Archivo | Para quién | Qué practica |
|---|---|---|
| `guia-colaborador-tecnico.md` | Colaborador técnico nuevo (no el Vibe Coder) | Qué implica trabajar con IA a su máximo potencial, paso a paso |
| `ejercicios-arquitecto.md` | Arquitecto | 8 ejercicios con solución: specs, tarjetas, revisión y casos de error |

## Plantilla para un ejercicio nuevo
```markdown
### Ejercicio N — <título>
**Practica:** <habilidad> · **Tiempo:** <min>
**Enunciado:**
**Entregable:**
**Solución esperada:**
```

## Ejemplo
Ejercicio 1 de `ejercicios-arquitecto.md`: "Escribe la tarjeta técnica y el encargo sencillo para agregar el archivo de transporte".
